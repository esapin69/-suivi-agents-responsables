# Cloudflare

Dossier dédié aux fichiers à utiliser ou déployer dans Cloudflare pour `responsable.esapin.com`.

Objectif : conserver ici une version claire et directement identifiable des fichiers Cloudflare, séparée des fichiers Google Apps Script (`apps-script`).

## Fichiers prévus

- `index.js` — Worker JavaScript compatible avec l’éditeur Cloudflare Dashboard.
- `README.md` — repères de déploiement et de maintenance.

Ne pas copier directement `backend/src/index.ts` dans un éditeur Cloudflare configuré en JavaScript : ce fichier source contient du TypeScript.
