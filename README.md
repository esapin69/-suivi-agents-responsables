# Suivi des agents responsables

Site interne de suivi de l’intégration des nouveaux agents.

## Squelette validé

- Accueil : **Suivi des agents** et **Prendre des notes**.
- Suivi : **Suivre un agent** et **Ajouter un agent**.
- Fiche agent : **Suivi d’intégration**, **Évaluations** et **Situations / événements**.

Les anciens formulaires ont été retirés. Aucun questionnaire n’est publié tant que son contenu n’a pas été validé.
